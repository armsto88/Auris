## Required external parts and equations

- Decoupling per pin table (p. 11): AVDD 0.1 + 10 µF (C103, C104), DVDD 0.1 + 10 µF (C108, C109), LDO 0.1 + 10 µF (C106, C107), VREF 1 µF (C105). TI's application figures 64/66 show 2.2 µF on VREF and LDO; 1 µF matches the pin table.
- I²C address: MS/AD low → 8-bit 0x94 → 7-bit 0x4A (Table 21).
- Clocking, checked against the register map:
  - `0x20 = 0x91` → SCK_XI_SEL = 10 (crystal), MST_SCK_SRC = 0 (SCK/XI), MST_MODE = 1 (master), CLKDET_EN = 1 (Table 54, p. 106). OK.
  - `0x26 = 0x07` → SCK ÷ 8 = 3.072 MHz BCK (Table 59, p. 108). OK.
  - `0x27 = 0x3F` → BCK ÷ 64 = 48 kHz LRCK (Table 60, p. 109). OK. Master mode allows BCK/LRCK of 32, 48, 64 or 256 only (note, p. 38): 64 is allowed.
  - Auto clock detection supports master mode at 256/384/512 × fS (§9.3.9.4.2): 24.576 MHz = 512 × 48 kHz. OK.
  - Expected read-back at step 10: `0x73` = 0x03 (32–48 kHz, Table 106) and `0x74` = 0x34 (BCK ratio 64, SCK ratio 512, Table 107).
- `0x0B = 0x44` → 24-bit RX and TX word length, I²S format (Table 37, p. 95). OK.
- Software reset: write 0xFE to register 0x00 (§13.1). README step 3 OK.
- Input select (Tables 32/33, pp. 91–92): bit 6 of 0x06 must be written 1 (0x07 bit 6 "do not access", reset 1, so writing 1 preserves it). `0x50` = {VIN1P,VIN1M} on ADC1L / {VIN2P,VIN2M} on ADC1R; `0x60` = {VIN4P,VIN4M} on ADC1L / {VIN3P,VIN3M} on ADC1R; `0x40` = no input. README mode tables agree with the pin numbers (3/1, 30/28, 4/2, 29/27).
- PGA (Table 27, p. 89): two's complement, 0.5 dB steps: `0x40` = +32 dB, `0x28` = +20 dB. OK. Gain changes need the DSP clocked, which master mode provides (§9.3.5 note) — README A1 is right.
- GPIO (Tables 42, 44, 46, 47): `0x10 = 0x00` sets pins 22/21 to GPIO0/GPIO1; `0x12 = 0x44` makes both push-pull outputs; in `0x14`, bit 4 = GPIO0_OUT (FILT_SEL0, U104 switch 1, R144) and bit 5 = GPIO1_OUT (FILT_SEL1, U104 switch 2, R145). So `0x10`/`0x20`/`0x30` select 100 Hz / 1 kHz / both. OK. At reset GPIO0 is a PDM input and GPIO1 a GPIO input, both with internal pull-downs enabled (0x15 reset 0x00) — together with R111/R112 the switches stay open until firmware writes them. OK.
- DSP_CTRL `0x71` (Table 104, p. 125): 0x10 = FIR + HPF (reset), 0x30 = low-latency IIR + HPF, 0x00 = FIR, HPF off. OK. Filter figures in README match §7.7.
- Mic bias: MIC_BIAS_CTRL (Page 3, 0x15) resets to 0x01 = **powered up** (Table 121, p. 132). Auris does not use it; power it down at init: `0x00 = 0x03`, `0x15 = 0x00`, `0x00 = 0x00` (register bits are write-only).
- Lowest standby power if the rail is ever left on: TI sequence in §11.5.1 (0x70 = 0x14; Page 3 0x12 = 0x41).

## Layout notes and gotchas

- Single ground plane, analog pins toward the front end (§12.1, Fig. 74); README layout rules already follow this.
- Unused-input stubs (AIN2x, AIN4x) are antennas into an off mux; keep them short and over ground.
- Crystal and C111/C112 tight to pins 9/10 (README rule 5).
- Fallback MCLK (R102) correctly lands on SCKI (3.3 V CMOS), not XI (1.8 V, abs. max 2.1 V). If it is ever used: remove R101, set SCK_XI_SEL = 01, and power the oscillator down (Page 3 0x12 = 0x41).
- The PCM has no reset pin; the only hard reset is cycling AUDIO_EN (U101 output discharges through 150 Ω).
- R108 and R110 duplicate the internal pull-downs on GPIO3/GPIO2 (Page 0 0x15 reset = pull-downs enabled). Harmless; could be removed.
