## Required external parts and equations

- **Supply switch-over** (p.9 Table 1, p.10): VCC > VPF → runs from VCC. VCC < VPF and VCC > VBAT → still VCC. VCC < VPF and VCC < VBAT → VBAT (temperature conversion every 10 s instead of 1 s). With KEEP_ALIVE ≥ 2.7 V the coin cell is idle.
- **INT on battery** (p.13): with BBSQW = 0 (power-up default; README writes it at every boot), INT/SQW goes high-impedance when VCC < VPF. Alarms then cannot wake the board, which cannot run anyway with the pack flat. Consistent with ADR-002/ADR-003.
- **RST left open**: the pin is an output plus push-button input with its own 50 kΩ pull-up (p.7). A noise pulse only produces a 250 ms reset pulse, and RST assertion does not affect the RTC's internal operation (p.10). NC is acceptable.
- **I²C pins at 0 V while VCC is powered** (sleep: pull-ups on the switched 3V3): SCL is an input with ±0.1 µA leakage and SDA is open-drain (p.3). Both tolerate pull-ups up to 5.5 V regardless of VCC (p.8), so there is no clamp to VCC and no back-powering. Holding both low is a valid idle-low level with only leakage current. Risk: if a read was cut by power-down, the RTC may still hold SDA low at the next wake. The datasheet's recovery is to toggle SCL until SDA is high, then issue a START (p.10–11).
- **VBAT capacitor** (p.10 "Initial VBAT Attachment"): contact bounce when the coin cell is inserted can corrupt memory recall. Preferred fix: apply VCC before inserting the cell. Alternative: 0.1–1 nF from VBAT to GND. C217 is 100 nF, outside that range.
- **Decoupling**: VCC 0.1–1.0 µF (p.7): C216 100 nF at pin 2: OK.

## Layout notes and gotchas

- C216 at pin 2; keep the RTC_VBAT trace short and guarded (nA leakage matters for backup life).
- The MEMS resonator needs no crystal; keep the part away from L201/L203 hot spots only for its ±3 °C temperature sensor accuracy.
- Firmware at every boot: INTCN = 1, BBSQW = 0, **EN32KHZ = 0**, clear A1F/A2F; run the I²C bus-clear before the first transaction.
